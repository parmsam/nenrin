# Code of Conduct

Nenrin adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, welcome newcomers, and keep criticism about the work, not the person. Harassment of any kind isn't tolerated.

To report a problem, use GitHub's private vulnerability and abuse reporting, or contact the maintainers through the repository. Reports are kept confidential.
