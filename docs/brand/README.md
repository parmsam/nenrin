# Nenrin brand

**Name:** Nenrin, 年輪 ("tree rings"). Write it "Nenrin" in prose; add the kanji 年輪 beside the wordmark where there's room, with ねんりん as furigana above it (`<ruby>年輪<rt>ねんりん</rt></ruby>`) so non-Japanese readers know how to say it.

**Tagline:** _Memory grows ring by ring._

**Logo:** a cross-section of a tree trunk. The off-centre pith and uneven rings are deliberate (real trees grow that way), and one accent ring stands for today's review.

| File           | Use                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------ |
| `logo.svg`     | Transparent mark for the README, docs, and in-app header                                         |
| `app-icon.svg` | Mark on a rounded dark square for app icons and favicons (the same file as `public/favicon.svg`) |

The logo is generated by `scripts/generate-brand.mjs`. Change the script and run `npm run brand`; don't hand-edit the SVGs. PNG app icons are generated at build time by `vite-plugin-pwa`.
